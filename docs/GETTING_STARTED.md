# 5 分钟上手指南

这份指南只解释第一次如何成功运行。环球慧思字段定义、筛选细节和维护命令分别放在其他文档，避免把开始路径变成长教程。

## 开始前

确认本机已有：

- Codex；
- Microsoft Edge；
- Node.js 与 `npx`；
- 能够登录并访问贸易搜索页面的环球慧思 GTIS 账号。

Skill 只会使用 Edge，不会启动 Chrome。账号密码、Cookie、Token、二维码和浏览器配置不会写入仓库或交付文件。

## 安装

在 PowerShell 中运行：

```powershell
git clone https://github.com/jedliuai/globalwits-ai-tradedata-search.git "$env:USERPROFILE\.codex\skills\globalwits-ai-tradedata-search"
```

如果目录已存在，进入该目录后运行 `git pull --ff-only` 即可升级。安装或升级后重新打开 Codex，让它重新发现 Skill。

## 发起第一次查询

一个容易执行的请求至少包含：

1. 产品名称和必须满足的限定词；
2. 时间范围；
3. 汇率与税率/含税系数；
4. 希望收到 Excel、文字还是两者；
5. 不确定记录的处理方式。

可以直接复制下面的格式：

```text
$globalwits-ai-tradedata-search 查询最近3个月磷霉素钠无菌原料的价格，
汇率6.8，含税系数1.13，拿不准的直接移除，输出Excel和逐条文字结果。
```

如果你需要特定国家、进口商、出口商、HS 编码或固定输出句式，一并写进请求即可。

## 什么时候需要你操作

Codex 会用 Edge 打开环球慧思。你只在以下情况接管：

- 首次扫码或账号登录；
- CAPTCHA、短信验证、多因素认证或设备风控；
- 会扣减额度、积分或费用的导出；
- 两种查询解释会显著改变结果，而原请求没有给出判断原则。

登录后回复“已登录”即可。搜索条件、分页提取、同义词补查、筛选、价格计算和交付由 Skill 继续完成。

## 如何判断一次交付是否完整

完整交付会说明实际查询周期、查询词、总命中数、保留数、关键排除原因、价格口径、汇率与含税系数，并给出文件位置。若站点只有较早月份的数据，也会明确写出实际可用的最新月份。

若某条记录不能确认产品、单位或价格口径，它默认不会混入结果。详细判定依据见 [筛选规则](../references/screening-rules.md) 和 [字段/价格口径](../references/field-map.md)。

## 常见阻塞点

- **页面回到登录页：** 重新完成登录，不要提供账号密码或 Cookie 给 Codex。
- **搜索没有结果：** 允许 Skill 补查多语言名称与拼写；不要仅因为一个关键词无结果就放宽产品限定。
- **导出提示消耗额度：** 先确认成本；也可以让 Skill 从当前可见页面提取，是否可行取决于页面与账号权限。
- **页面字段改变：** 以当前表头和完整货描为准，不使用历史列号硬套。

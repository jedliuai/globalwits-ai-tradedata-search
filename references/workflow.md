# 操作流程

## 1. 将需求转成查询规格

从用户请求提取：目标产品及必需限定词、时间范围、贸易方向、国家或公司限制、价格字段与单位、汇率、税率或含税系数、Excel 列、文字输出句式，以及对不确定记录的处理原则。

“最近 N 个月”默认解释为当前月加此前 `N-1` 个自然月。若当前月没有数据，则以站点实际最新数据月为终点，向前取 N 个自然月，并在交付中写明实际范围。用户明确要求滚动天数时按其要求执行。

## 2. 打开 Edge 并登录

检查 `npx` 后，通过 Playwright CLI 使用命名会话和任务内持久化目录：

```powershell
npx --yes --package @playwright/cli playwright-cli -s=globalwits open "https://g6.globalwits.cn/tradesearch/index" --browser msedge --headed --persistent --profile "<task>/work/playwright/edge-profile"
```

如果跳到登录页，按 `user-checkpoints.md` 暂停并让用户扫码。登录后重新 snapshot，确认 URL、页面标题和用户已进入系统。

## 3. 设置搜索条件

1. 打开“贸易搜索”。
2. 设置月份，记录真实起止月。
3. 先用能覆盖拼写、词序和语言差异的核心产品词搜索。
4. 每个核心词单独查询，避免站点算法把多个同义词错误地当成必须同时满足。
5. 对可能的英文、西语、葡语或历史拼写补查。把所有查询词记录到交付说明。

示例：磷霉素可依次补查 `FOSFOMYCIN`、`FOSFOMICINA`、`PHOSPHOMYCIN`。这只是召回词；最终仍须按完整货描严格筛选。

## 4. 提取全部结果

- 优先从结果表 DOM 读取标题和每一行；先确认列顺序，再提取。
- 遍历所有分页，记录页数、表格行数和站点返回的总数。
- 页面超时后分批读取，例如每批 3–4 页，避免因单次自动化时限丢失结果。
- 可以查看浏览器网络请求以核对总数或字段含义，但不要复制鉴权头、Cookie 或令牌到脚本、日志、工作簿或仓库。
- 对同一查询的重复行按稳定业务字段去重，例如日期、货描、出口国、进口国、总额、单价、重量和数量的组合。

## 5. 严格筛选

按 `screening-rules.md` 建立“必须满足的词组”和“任何一个命中即排除的否定词”。先检测否定语义，再检测肯定语义。

对每条保留记录人工复看完整货描。若截断，展开详情或读取原始行内容。不同盐型、制剂、实验室试剂、非无菌品、描述不完整或单位无法可靠换算的记录应排除。

## 6. 价格与单位

按 `field-map.md` 确认单价、总额、重量、数量和单位。只在公斤口径明确时输出“美元/kg”。

默认计算：

- 人民币未税单价 = 美元单价 × 汇率
- 人民币含税单价 = 人民币未税单价 × 含税系数

显示值通常保留 2 位小数，底层公式保留完整精度。不要根据显示值反推原始价格。

## 7. Excel 和文字输出

Excel 至少包含：月份、日期、出口国、进口国、完整货描、出口商、进口商、HS 编码、美元总额、美元单价、数量/重量、单位、汇率、人民币未税价、含税系数、人民币含税价、数据源、来源链接和筛选备注。

正文按照用户给定句式逐条输出。例如：

```text
2026年8月印度出口印度尼西亚，FOB美金单价280美元/kg，折合人民币1904元/kg，含税人民币2151.52元/kg，数量25kg。
```

## 8. 质量检查

- 结果数量与各页提取数量一致；
- 所有保留记录满足每项限定词且不含否定语义；
- 美元总额约等于单价 × 公斤数量（若字段定义允许）；
- Excel 公式无错误，日期与数字为正确类型；
- 文件视觉检查无截断、乱码或不可读列；
- 关闭 Edge 会话并清理任务内临时登录资料，除非用户要求保留会话。

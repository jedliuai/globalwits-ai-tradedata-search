# 用户介入节点

只在下面这些节点暂停自动化并等待用户。其余页面导航、查询、翻页、提取、筛选、计算和文件生成由代理继续完成。

## 必须由用户操作

1. **扫码或账号登录**
   - 代理用 Edge 打开登录页后，告诉用户完成扫码/登录并回复“已登录”。
   - 用户完成前不要反复刷新，不要尝试读取二维码或登录凭据。

2. **CAPTCHA、MFA 或风控验证**
   - 页面出现验证码、短信确认、设备确认或账号风控时，说明页面要求并等待用户完成。
   - 不得规避、代答或自动破解。

3. **付费、额度或有成本的导出**
   - 如果点击导出会扣减次数、积分、费用或产生不可逆影响，先告诉用户具体影响并取得确认。

4. **查询口径会实质改变结果**
   - 只有在用户没有给出处理原则且不同解释会显著改变结果时才询问。
   - 如果用户已经说“拿不准的直接移除”，代理应自动排除，不要逐条打断用户。

## 不需要用户操作

- 选择数据源、填写月份和关键词。
- 切换页面、调整每页条数、读取所有分页。
- 扩展同义词或语言变体后补查。
- 排除不同盐型、成品制剂、试剂、非无菌品或单位不可换算的数据。
- 汇率、税率计算和 Excel 生成。

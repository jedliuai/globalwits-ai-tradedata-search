# 环球慧思字段与价格口径

GTIS 页面会因数据源、模板和账号权限变化。每次以当前表头为准，不依赖固定 DOM 引用。

常见结果列：

| 页面字段 | 常见键 | 用途 |
|---|---|---|
| 日期 | `Dates` | 交易或关单日期 |
| 海关编码 | `HSCODE` | HS 编码 |
| 货物描述 | `ProductDesc1` | 产品筛选的主要证据 |
| 供应商 | `Exporter1` | 出口商/发货人 |
| 采购商 | `Importer1` | 进口商/收货人 |
| 原产国 | `OrgCountry` | 默认用于“出口国”，但要核对数据源定义 |
| 目的国 | `DesCountry` | 默认用于“进口国” |
| 总额($) | `TotalPrice` | 美元总额 |
| 单价($) | `UnitPrice` | 页面计算或原始单价 |
| 千克重量 | `WT` | 公斤重量 |
| 数量 | `QTY` | 按 `UNIT` 解释的数量 |
| 单位 | `UNIT` | `KGM`、`UNT`、`PKG` 等 |

## FOB 口径

页面“单价($)”不一定天然等于 FOB。按以下优先级判断：

1. 交易条款或字段明确写 `FOB`：可标注 FOB；
2. 数据源文档明确该价格口径为 FOB：可标注 FOB 并写出依据；
3. 用户明确要求把站点单价作为 FOB 使用：可以按其业务口径输出，但在工作簿备注“按用户口径将页面单价视为 FOB”；
4. 以上均不满足：写“页面美元单价”，不要自行改成 FOB。

## 单位换算

- `KGM` / `KG`：可直接作为美元/kg；
- `TNE` / `TON`：只有总额与吨数清晰时才能除以 1000 换为 kg；
- `UNT` / `PCS` / `PKG` / `OTHERS`：不要自动转为 kg，除非另有可靠净重字段且能与该行总额对应；
- 同时存在 `WT` 和 `QTY` 时，优先用明确的公斤重量验证单价，不要假设件数等于公斤数。

进行 `总额 ÷ 公斤重量` 与页面单价的近似校验。差异明显时保留原始字段、暂停该行纳入并查明数据定义。
